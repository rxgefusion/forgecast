# ForgeCast

A Fabric mod for Hypixel SkyBlock that tracks forge timers and recipe progress.

> **Early development.** ForgeCast is not feature-complete and is not yet
> recommended for general use.

## Requirements

| | |
| --- | --- |
| Minecraft | 26.1.2 |
| Mod loader | Fabric |
| Java | 25 |

## Building from source

```
./gradlew build
```

The built jar is written to `build/libs/`.

To run a development client:

```
./gradlew runClient --console=plain
```
